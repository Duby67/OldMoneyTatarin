# OldMoneyTatarin

OldMoneyTatarin — планируемый Minecraft-лаунчер на основе PineconeMC, форка Prism Launcher. Текущий этап — подготовка репозитория, исследование исходников и проверка исходной сборки.

- Пиши документацию и отчёты на русском языке; сохраняй исходные имена API, файлов и команд.
- До отдельного задания не реализуй MCP Sync, новые функции, ребрендинг интерфейса, установщик или обновление лаунчера.
- Сохраняй существующие механизмы Ely.by, скинов, установки Minecraft, загрузчиков и сборок. Минимизируй отличия от upstream.
- Не перезаписывай существующие файлы при получении upstream. План интеграции исходников описан в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
- Не изменяй системные настройки и не устанавливай глобальные зависимости без необходимости; предпочитай изолированное окружение сборки.
- Сохраняй сведения об авторах, лицензии и уведомления upstream и зависимостей. Не объявляй лицензию форка до проверки исходников.
- Не сохраняй в Git и отчётах токены Ely.by, пароли, cookies, ключи подписи и пользовательские данные.
- Не выдавай предполагаемые пути и компоненты за проверенные; отмечай непроверенные сведения и пропущенные проверки.
- Коммиты, push, PR и merge выполняй только по отдельному поручению пользователя.
- Запускай дополнительных агентов только по разрешению пользователя.

## Ветки

Планируемая рабочая ветка — `develop`, ветка выпусков — `main`. После получения исходников сначала проверь реальные ветки upstream; отсутствие этих веток отрази в отчёте. Создание веток выполняется на этапе подготовки Git-репозитория. Рабочие PR направляй в `develop`; слияние в `main` допускается после успешных проверок выпуска.
