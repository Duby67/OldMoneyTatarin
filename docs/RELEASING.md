# Выпуск

## Версия

Единственный источник версии продукта — `VERSION`: одна строка `vX.Y.Z` без ведущих нулей и суффиксов. CMake получает из неё версию приложения `X.Y.Z` и Windows-ресурсов `X.Y.Z.0`. Версия OldMoneyTatarin не зависит от номера PineconeMC.

## Патчноуты

В `CHANGELOG.md` записываются только изменения поведения лаунчера. До выпуска они находятся под `## [Не выпущено]`, затем переносятся в датированный раздел:

```markdown
## [v0.1.0] — YYYY-MM-DD

### Исправлено

- Описание исправления для пользователя.
```

Укажите реальную календарную дату. Заголовок версии должен быть уникальным, раздел — содержать хотя бы один пункт. Из него извлекается текст до следующего заголовка версии.

Подготовка патчноутов в PowerShell:

```powershell
$releaseTag = (Get-Content -Raw VERSION).Trim()
python scripts/prepare_release.py --tag $releaseTag --notes-file release-notes.md
```

Скрипт проверяет совпадение тега с `VERSION` и формат раздела. Для версии, которая ещё не оформлена в `CHANGELOG.md`, он завершится с ошибкой. Локальный `release-notes.md` исключён из Git.

## Порядок выпуска

1. Обновить `VERSION` и подготовить раздел патчноутов.
2. Локально [собрать приложение](DEVELOPMENT.md), проверить Ely.by, установку и запуск игры, обновление существующего профиля.
3. Проверить состав пакета, условия распространения и подпись перед передачей пользователям.
4. По отдельному поручению перенести проверенное состояние `develop` в `main` и создать тег с точным значением `VERSION`. При первом выпуске создать `main`.
5. Разместить готовые файлы вне GitHub после выбора канала распространения.

Теги не запускают сборку или публикацию. GitHub хранит код и документацию; сборка и упаковка выполняются локально. Скрипт `prepare_release.py` не создаёт теги, не собирает приложение и ничего не публикует.

## Локальный установщик Windows

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -Jobs 6 -Installer
```

CMake ищет локальный Inno Setup 6 (`ISCC.exe`) в PATH, реестре и стандартных папках.
Другой путь можно задать через `-DOldMoneyTatarin_ISCC_EXECUTABLE=<путь-к-ISCC.exe>`
при конфигурации CMake. Обычная сборка не требует Inno Setup.
После конфигурации доступна также команда:

```powershell
cmake --build dist/build/windows_msvc --config Release --target installer
```

Цель `installer` готовит чистую установку приложения в каталоге сборки, добавляет
распространяемые библиотеки MSVC и уведомления лаунчера, затем компилирует
`installer/windows.iss.in`. Результат — `dist/installer/OldMoneyTatarin-X.Y.Z-Setup-x64.exe`;
версия берётся из `VERSION`. Упаковка разрешена только для Release.

Мастер на русском: выбор папки → установка → завершение. Папка по умолчанию —
`%LOCALAPPDATA%\Programs\OldMoneyTatarin`, при повторной установке сохраняется
ранее выбранная папка. Установка выполняется для текущего пользователя без
запроса администратора и создаёт ярлык в меню «Пуск». Выбора компонентов,
дополнительных задач, языка и предложения запуска приложения нет.
Лицензии включены в файлы пакета без отдельного шага принятия.
Удаление через стандартный деинсталлятор не очищает пользовательские данные лаунчера.
Подпись установщика пока не настроена.

Проверены компиляция Inno Setup, тихая установка в отдельную тестовую папку,
наличие библиотек runtime и лицензий, удаление приложения и сохранность
постороннего файла после удаления. Последовательность экранов задана в сценарии;
визуальная проверка мастера пока не выполнялась.

Источник обновлений с собственного хостинга, подпись манифестов и процедура замены файлов лаунчера ещё не реализованы. Текущий `Launcher_UPDATER_GITHUB_REPO` указывает на наш репозиторий, где бинарники не публикуются, поэтому рабочим каналом обновления он не является. Внутренние имена и оформление upstream пока сохранены.
