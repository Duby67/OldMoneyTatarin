# Локальная разработка TATARIN

Исходная игровая папка используется только для чтения. Снимки и раздача хранятся в
`run/`, исключённом из Git. Не добавляйте туда ссылки на исходные пользовательские папки.

## Снимок

Из корня репозитория, с Python 3.12 или новее:

```powershell
python scripts/tatarin/snapshot.py <исходная-папка> run/tatarin/snapshot-v1 --minecraft 1.21.1 --neoforge 21.1.264
```

Скрипт требует новый каталог назначения. Разрешённые корневые папки и политика
файлов перечислены в `scripts/tatarin/snapshot.py`. Миры, карты, история, кеши,
пользовательские файлы в корне и резервные копии не входят в снимок.
Конфиги с обнаруженными непустыми полями учётных данных исключаются без вывода значений.
Это дополнительный фильтр, а не гарантия обезличивания произвольных файлов:
перед публичной раздачей требуется ручная проверка состава и содержимого.

`snapshot.json` содержит только версии компонентов, относительные пути, размеры,
SHA-256 и политику файлов. `managed` означает управление сборкой, `seed` —
начальное содержимое с сохранением последующих пользовательских изменений.
Файлы вне разрешённых папок необходимо разбирать отдельно, не копировать автоматически.
