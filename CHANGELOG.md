# Изменения OldMoneyTatarin Launcher

Порядок подготовки патчноутов описан в [инструкции выпуска](docs/RELEASING.md).

## [v0.4.0](https://github.com/Duby67/OldMoneyTatarin/releases/tag/v0.4.0) — 2026-11-15

### Добавлено

- Флажок «Открыть лаунчер» на последней странице установщика.
- Локальная цифровая подпись приложения и установщика сертификатом TATARIN. Сертификат самоподписанный и не обеспечивает доверие Windows на других компьютерах.

### Изменено

- Новая иконка OMT для приложения, ярлыков и установщика.
- Каталог сборок TATARIN использует HTTPS-сервер play.fleexpoint.space:8443. RegionalWorlds с прежним локальным источником переводится на сервер при обновлении с сохранением клиентских данных.
- В Windows-ресурсах указана компания TATARIN Co., в установщике — издатель TATARIN.

## [v0.3.0](https://github.com/Duby67/OldMoneyTatarin/releases/tag/v0.3.0) — 2026-11-15

### Добавлено

- Требования сборок TATARIN к памяти Java и предупреждение при недостатке установленной или свободной RAM. Параметры управляемой сборки задаются её манифестом.
- Перенос клиентских данных из игровой папки другого лаунчера: настройки, карты и точки, список серверов, ресурспаки, шейдеры, миры и скриншоты. Добавлены предварительная проверка, резервные копии и восстановление после сбоя.

### Изменено

- Сокращён текст выбора каталога сборок в быстрой настройке.
- Версия лаунчера отображается без суффикса ветки: OldMoneyTatarin 0.3.0.

## [v0.2.0](https://github.com/Duby67/OldMoneyTatarin/releases/tag/v0.2.0) — 2026-11-15

### Добавлено

- Автоматическая проверка обновлений лаунчера при запуске и ручная проверка GitHub Releases, с результатом в строке состояния и настройках.
- Уведомление о новой стабильной версии с патчноутом и кнопкой открытия страницы выпуска; отдельный адрес источника для локальных проверок.

- Выбор общей папки сборок при быстрой настройке и отображение её пути в каталоге TATARIN.

- Локальный установщик Windows: выбор папки, установка для текущего пользователя и завершение без дополнительных этапов.

- Локальный каталог сборок TATARIN, установка и синхронизация перед запуском с проверкой SHA-256 и восстановлением после сбоя.
- Сохранение стартовых настроек и дополнительных модов, резервные копии заменяемых файлов, страница состояния TATARIN в настройках экземпляра.

### Исправлено

- В названиях окон используется OldMoneyTatarin; после браузерной авторизации показывается локальная страница без перехода на сайт upstream.
- Профиль Windows по умолчанию хранится в OldMoneyTatarin; для прежнего профиля предлагается копирование с сохранением исходника.

- База лаунчера переведена на стабильный PineconeMC 11.1.2, содержащий исправление проверки пути при импорте CurseForge-модпаков и исправление авторизации Ely.by.

### Изменено

- Введена собственная версия OldMoneyTatarin, независимая от версии PineconeMC.

- Русский перевод поставляется вместе с приложением и выбирается по умолчанию; автоматическая загрузка переводов отключена.
- Правовые уведомления перенесены из окна «О программе» в общие настройки.

### Удалено

- Новости PineconeMC, ссылки на сообщества и внешнюю справку upstream.
- Фоновые проверки доступности сайтов PineconeMC. Ручной выбор серверов метаданных сохранён.
- Публикация журналов во внешние сервисы и загрузка скриншотов в Imgur. Локальные просмотр и копирование сохранены.
- JProfiler, VisualVM и Generic Profiler, включая пункты меню запуска.
- Пасхалка Konami, CatPack, анимированные и праздничные фоны и их настройки. Обычные темы сохранены.
