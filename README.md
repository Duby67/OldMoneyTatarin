# OldMoneyTatarin Launcher

Проект собственного Minecraft-лаунчера на основе PineconeMC — форка Prism Launcher. Основная целевая платформа — Windows 10/11 x64; планируемый стек — C++, Qt6 и CMake.

Источник исходников по заданию: [ElyPrismLauncher/Launcher](https://github.com/ElyPrismLauncher/Launcher). Соответствие репозитория названию PineconeMC, актуальную ветку и условия использования необходимо проверить при получении исходников.

## Текущее состояние

Создана русскоязычная документация подготовительного этапа. Исходники upstream ещё не добавлены, Git-репозиторий и ветки не подготовлены. Зависимости, архитектура исходного проекта и лицензии не проверены; сборка и запуск не выполнялись.

## Целевое назначение

- Авторизация Ely.by и поддержка скинов.
- Установка Vanilla Minecraft, Forge, NeoForge и Fabric.
- Установка готовых сборок из существующих каталогов.
- Отдельный управляемый профиль MCP с автоматической синхронизацией модпака.
- Автоматическая установка Java и настройка оперативной памяти.
- Собственный установщик и механизм обновления лаунчера.

Это требования к будущему продукту, а не перечень проверенных возможностей текущей папки. Значение MCP и источник модпака предстоит уточнить перед проектированием синхронизации.

## Границы текущего этапа

Следующая подготовительная работа — получить upstream без потери этих документов, исследовать код и лицензии, попробовать собрать неизменённый лаунчер и зафиксировать результат. Разработка функций и переработка интерфейса начинаются только по отдельному заданию.

Лицензия проекта пока не установлена. Эти документы не предоставляют разрешений на распространение исходников upstream, его зависимостей, Minecraft, Java или модпаков.
