# OldMoneyTatarin Launcher

Minecraft-лаунчер на основе [PineconeMC](https://github.com/ElyPrismLauncher/Launcher), форка Prism Launcher. Платформа — Windows 10/11 x64; C++, Qt6 и CMake.

После очистки проверены локальная Release-сборка, линковка и установка приложения с зависимостями в `dist/app/windows_msvc`. Запуск интерфейса, авторизация и игровые сценарии после очистки пока не проверялись. Версия продукта хранится в [VERSION](VERSION), патчноуты — в [CHANGELOG.md](CHANGELOG.md). Собственные релизы ещё не опубликованы.

## Сборка

После подготовки зависимостей:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -Jobs 6 -Install
```

Приложение появится в `dist/app/windows_msvc/elyprismlauncher.exe`. Бинарники собираются локально и исключены из Git; на GitHub хранятся код и документация.

## Текущая основа

Сохранены авторизация и скины Ely.by, установка Minecraft, загрузчиков и публичных модпаков, управление Java, локальные журналы и скриншоты. Русский перевод включён в ресурсы приложения; фоновой загрузки переводов нет.

Удалены новости и социальные ссылки upstream, фоновые проверки доступности сайтов PineconeMC, публикация логов и скриншотов, профилировщики и декоративные фоны. Правовые уведомления доступны в общих настройках, отдельного окна «О программе» нет.
