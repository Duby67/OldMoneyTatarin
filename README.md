# OldMoneyTatarin Launcher

Проект собственного Minecraft-лаунчера на основе PineconeMC — форка Prism Launcher. Основная целевая платформа — Windows 10/11 x64; планируемый стек — C++, Qt6 и CMake.

Источник исходников: [ElyPrismLauncher/Launcher](https://github.com/ElyPrismLauncher/Launcher), стабильный релиз `11.1.2`. Точный commit и порядок обновления зафиксированы в [подготовке окружения](docs/DEVELOPMENT.md).

## Текущее состояние

Подготовлена стабильная база PineconeMC и отдельная ветка `vendor/pineconemc` с полной историей upstream. `develop` — рабочая ветка нашего проекта, `main` предназначена для выпусков. Настроены собственный `origin` и исходный `upstream`.

Цель разработки — только Windows 10/11 x64. Сборка и упаковка выполняются локально; на GitHub хранятся код и документация, без автоматической сборки и публикации исполняемых файлов. Структуру исходного проекта сохранять не требуется: ненужные файлы можно удалять в `develop`, сохраняя лицензионные уведомления и нужные функции. Зависимости, архитектура и условия распространения ещё требуют исследования; сборка и запуск приложения не проверены.

Собственная версия продукта хранится в [VERSION](VERSION), патчноуты — в [CHANGELOG.md](CHANGELOG.md). Релизы OldMoneyTatarin ещё не опубликованы.

## Структура корня

| Файлы и каталоги | Назначение |
| --- | --- |
| `CMakeLists.txt`, `CMakePresets.json`, `vcpkg*.json` | Локальная сборка и зависимости |
| `VERSION`, `CHANGELOG.md` | Версия продукта и патчноуты |
| `LICENSE`, `COPYING.md` | Лицензия и уведомления об авторах; `COPYING.md` также встроен в приложение |
| `.gitignore`, `.gitattributes`, `.gitmodules` | Правила Git и субмодуль |
| `.clang-format`, `.clang-tidy` | Настройки инструментов C++, на которые ссылается CMake |
| `AGENTS.md`, `docs/` | Правила работы и документация |
| `launcher/`, `libraries/`, `buildconfig/`, `cmake/`, `program_info/` | Исходники, библиотеки и ресурсы сборки |
| `scripts/`, `tools/`, `tests/` | Вспомогательные скрипты и проверки; детальная очистка ещё не проводилась |

Файлы командной работы upstream, GitHub-автоматизация, контейнерное и Nix-окружение удалены из рабочей ветки. Их исходные версии доступны в `vendor/pineconemc`.

## Целевое назначение

- Авторизация Ely.by и поддержка скинов.
- Установка Vanilla Minecraft, Forge, NeoForge и Fabric.
- Установка готовых сборок из существующих каталогов.
- Отдельный управляемый профиль с автоматической синхронизацией модпака.
- Автоматическая установка Java и настройка оперативной памяти.
- Собственный установщик и механизм обновления лаунчера.

Это требования к будущему продукту, а не перечень проверенных возможностей текущей папки. MVP — первая рабочая версия продукта; её состав и источник модпака предстоит уточнить перед реализацией.

## Границы текущего этапа

Следующая подготовительная работа — исследовать код и лицензии, подготовить зависимости Windows x64, попробовать собрать неизменённый лаунчер и зафиксировать результат. Разработка функций и переработка интерфейса начинаются только по отдельному заданию.
