# OldMoneyTatarin

Minecraft-лаунчер для Windows 10/11 x64 на основе [PineconeMC](https://github.com/ElyPrismLauncher/Launcher), форка Prism Launcher.

Поддерживает аккаунты и скины Ely.by, установку Minecraft и загрузчиков модов,
сборки TATARIN с обновлением файлов с сервера, перенос клиентских данных из
других лаунчеров и проверку новых версий приложения. Интерфейс на русском языке.
