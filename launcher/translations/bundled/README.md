# Русский перевод

Источник: [PrismLauncher/Translations](https://github.com/PrismLauncher/Translations), ревизия `e597d292ec6d16d79197a611b5841ec34812161c`.

`ru.ts` сохранён из upstream без изменений. Условия использования находятся в `LICENSE` рядом с переводом. CMake компилирует `ru.ts` через `Qt6::lrelease` и включает `ru.qm` в ресурсы приложения. Для этого нужен Qt LinguistTools. Пакет загружается локально; сетевое обновление переводов отключено. Перевод из Prism Launcher может не покрывать строки, добавленные PineconeMC.
